# Pypestream Homebrew Tap

Public Homebrew tap for Pypestream-built command line tools.

```sh
brew tap pypestream/tap
```

| Formula | Tool | Published by | Source of releases |
|---|---|---|---|
| [`localdev.rb`](localdev.rb) | `localdev` — local Kubernetes development | Jenkins, on each `localdev` release | `fs.gcp.pype.tech` (**VPN required**) |
| [`maestro.rb`](maestro.rb) | `maestro` — compiler for the Pypestream Maestro DSL | [`pypestream/maestro-compiler`](https://github.com/pypestream/maestro-compiler) release workflow, on each version tag | `maestro-cli.main.pypestream.dev` (public) |

Both formulae live side by side in this one tap. They are updated by separate
automations that each commit only their own `.rb` file, so a release of one
never touches the other.

## localdev

Requires VPN — the formula checks `fs.gcp.pype.tech` before installing and
aborts with a clear message if the internal network is unreachable.

```sh
brew install pypestream/tap/localdev
localdev --version

brew update && brew upgrade pypestream/tap/localdev
```

## maestro

> **Not installable yet.** The formula is disabled until the first build is
> published to `maestro-cli.main.pypestream.dev`. `brew install` refuses with an
> explanatory error rather than failing on a missing download.

```sh
brew install pypestream/tap/maestro
maestro version

brew update && brew upgrade pypestream/tap/maestro
```

The tool is also installable without Homebrew:

```sh
curl -fsSL https://maestro-cli.main.pypestream.dev/install.sh | sh
```

`maestro` self-updates with `maestro upgrade`, which reads the same
distribution, so Homebrew is one option rather than the only one.

## Formula maintenance

Neither `.rb` file is edited by hand.

- **`localdev.rb`** is regenerated by the Jenkins release job, which rewrites the
  version, URLs and checksums and pushes a single-file commit.
- **`maestro.rb`** is regenerated by `scripts/update-brew-tap.sh` in
  `pypestream/maestro-compiler`, run by that repo's release workflow on a version
  tag (`X.Y.Z`, no `v` prefix). It renders the formula from `dist/checksums.txt`,
  writes `maestro.rb` only, and pushes to `main` here using `HOMEBREW_TAP_TOKEN`
  — a token scoped to `contents: write` on this repository.

If a publish ever needs to be done by hand, run the generator rather than
editing the formula:

```sh
# in a pypestream/maestro-compiler checkout, after `make build-all && make checksums`
TAP_PUSH_URL="git@github.com:pypestream/homebrew-tap.git" scripts/update-brew-tap.sh 0.4.0
```

## Troubleshooting

- Make sure Homebrew itself is current: `brew update`.
- `localdev` install failures are usually VPN — reconnect and retry.
- `maestro` download failures point at the distribution, not the tap; check
  `https://maestro-cli.main.pypestream.dev/` and see
  [`docs/DISTRIBUTION.md`](https://github.com/pypestream/maestro-compiler/blob/main/docs/DISTRIBUTION.md).
- Anything else: open an issue in this repository.
